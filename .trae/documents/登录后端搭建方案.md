### 3. `server/db.py`（新增）—— 数据层

**How**：PyMySQL 请求级连接复用（不引入连接池依赖）：

| 函数 | 说明 |
|---|---|
| `get_conn()` | 当前请求的连接，存于 `flask.g`，`cursorclass=DictCursor`、`autocommit=False` |
| `close_db(exc=None)` | 关闭并清理连接，注册到 `app.teardown_appcontext` |
| `query_one(sql, args=None)` | 返回单行 `dict` 或 `None` |
| `query_all(sql, args=None)` | 返回 `list[dict]` |
| `execute(sql, args=None)` | 写操作 + `commit()`，返回 `cursor.lastrowid` |
| `paginate(sql_count, sql_list, args=None, page=1, page_size=10)` | 先 `COUNT(*)` 再分页查询，返回 `(items, total)`，供未来列表接口一行搞定分页 |

全部走 `%s` 占位符参数化，禁止 SQL 拼接。

### 4. `server/utils/params.py`（新增）—— 统一参数处理

**Why**：后续每个接口都要取参、校验必填，抽出来避免重复与崩溃。
**How**：

| 函数 | 说明 |
|---|---|
| `get_body()` | `request.get_json(silent=True) or {}`，修正文档的 `None` 缺陷 |
| `clean(value)` | 非字符串转字符串后 `strip()`，`None` → `""` |
| `require(body, *fields)` | 返回缺失字段名列表，供接口拼 1001 提示 |
| `is_valid_email(email)` | 常规正则校验 |
| `parse_page_args()` | 从 query 读 `page`/`page_size`，默认 1/10，`page_size` 上限 50，非法值回归默认 |

### 5. `server/utils/token.py` + `server/utils/auth.py`（新增）—— 登录态

**Why**：这是「方便后续接口对接」的关键。没有登录态，后续任何需要「当前用户」的接口（发帖、回帖、个人中心、点赞）都无法落地。用 Flask 自带的 itsdangerous，不引入 JWT 新依赖。
**How**：

- `token.py`：`generate_token(user_id)` → `URLSafeTimedSerializer(Config.SECRET_KEY, salt="yunmo-api")` 签名；`parse_token(token)` → 用 `TOKEN_EXPIRE_SECONDS` 校验时效，返回 `user_id` 或 `None`
- `auth.py`：`@login_required` 装饰器——从 `Authorization: Bearer <token>` 取 token，校验失败返回 `1007`「登录状态无效或已过期」；成功则把 `{"id", "username", "role"}` 写入 `g.current_user`，接口内直接用 `g.current_user["id"]`；另提供 `get_current_user()` 读取

### 6. `server/api/auth.py`（新增）—— 本次正式接口

`bp = Blueprint("auth", __name__, url_prefix="/api")`

**`POST /api/register`**

1. `get_body()` 兜底取参；`clean` 处理 `username`、`password`、`email`、`nickname`
2. 校验 `password` 长度 6–20、`email` 非空且格式合法 → 不通过返回 `1001`（提示到具体字段）
3. `username` 为空 → 随机生成 `yunmo_` + 6 位随机小写字母数字（冲突最多重试 10 次）；非空 → 查重命中返回 `1002`「该用户名已被注册」
4. 邮箱查重命中 → `1003`「该邮箱已被注册」
5. `nickname` 为空则默认等于 `username`
6. `generate_password_hash(password)`（`werkzeug.security`，Flask 自带 PBKDF2）
7. `INSERT INTO users (username, password, email, nickname) VALUES (%s, %s, %s, %s)`
8. 返回 `make_response(0, "注册成功", {"id", "username", "nickname", "email"})`，**不含密码**
9. `pymysql.MySQLError` → `2000`「数据库操作失败」

**`POST /api/login`**

1. 取 `username`、`password`，任一为空 → `1001`
2. `SELECT id, username, password, email, nickname, avatar, followers_count, likes_count, following_count, role, status FROM users WHERE username=%s`
3. 无记录 → `1004`；`check_password_hash` 失败 → `1005`；`status == 0` → `1006`
4. 成功 → `make_response(0, "登录成功", {id, username, nickname, avatar, email, followers_count, likes_count, following_count, role, token})`
   - `token = generate_token(user["id"])`，前端存入 localStorage，后续请求带 `Authorization: Bearer <token>`
   - 字段对应文档「昵称/头像/粉丝数/点赞数/关注数/身份」，**不含密码**

### 9. `server/sql/schema.sql`（新增）

**Why**：文档第 3 点要求设计登录/注册/发帖/回帖数据库。
**How**：建 `yunmo` 库（utf8mb4 / utf8mb4_general_ci）+ 三张 InnoDB 表。**统一 `CREATE TABLE IF NOT EXISTS`**，脚本可重复执行、不做破坏性删除；需重建时由人工手动 `DROP`。因 `init_db.py` 按分号切分，文件中不使用行内 `--` 注释，说明性注释单独成行。

```sql
CREATE DATABASE IF NOT EXISTS `yunmo` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
USE `yunmo`;

CREATE TABLE IF NOT EXISTS `users` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` VARCHAR(50) NOT NULL COMMENT '登录账号',
  `password` VARCHAR(255) NOT NULL COMMENT '密码（werkzeug 哈希值）',
  `email` VARCHAR(100) NOT NULL COMMENT '邮箱',
  `nickname` VARCHAR(50) NOT NULL DEFAULT '' COMMENT '昵称',
  `avatar` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '头像地址',
  `followers_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '粉丝数',
  `likes_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '获赞数',
  `following_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '关注数',
  `role` TINYINT NOT NULL DEFAULT 0 COMMENT '身份：0-普通用户 1-管理员',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1-正常 0-禁用',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`),
  UNIQUE KEY `uk_email` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';

CREATE TABLE IF NOT EXISTS `posts` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '帖子ID',
  `user_id` INT UNSIGNED NOT NULL COMMENT '作者ID',
  `title` VARCHAR(200) NOT NULL DEFAULT '' COMMENT '标题',
  `content` TEXT COMMENT '正文',
  `cover` VARCHAR(255) NOT NULL DEFAULT '' COMMENT '封面图',
  `view_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '浏览数',
  `like_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '点赞数',
  `reply_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '回帖数',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1-已发布 0-草稿',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_create_time` (`create_time`),
  CONSTRAINT `fk_posts_user` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='帖子表';

CREATE TABLE IF NOT EXISTS `replies` (
  `id` INT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '回复ID',
  `post_id` INT UNSIGNED NOT NULL COMMENT '所属帖子ID',
  `user_id` INT UNSIGNED NOT NULL COMMENT '回复人ID',
  `parent_id` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '父回复ID，0 表示直接回帖',
  `content` TEXT NOT NULL COMMENT '回复内容',
  `like_count` INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '点赞数',
  `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1-正常 0-隐藏',
  `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  KEY `idx_post_id` (`post_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_parent_id` (`parent_id`),
  CONSTRAINT `fk_replies_post` FOREIGN KEY (`post_id`) REFERENCES `posts` (`id`) ON DELETE CASCADE,
  CONSTRAINT `fk_replies_user` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='回帖表';
```

| GET | `/api/posts` | 否 | 预留示例：帖子分页列表；query `page`、`page_size` |
| GET | `/api/user/profile` | **是** | 预留示例：当前登录用户信息；header `Authorization: Bearer <token>` |

统一响应：`{"code": 0, "message": "...", "data": {...}}`；分页接口 `data = {list, total, page, page_size, total_pages}`。
错误码：`1001` 参数错误 / `1002` 用户名已注册 / `1003` 邮箱已注册 / `1004` 用户不存在 / `1005` 密码错误 / `1006` 账号禁用 / `1007` 登录态失效 / `1008` 无权访问 / `1009` 资源不存在 / `2000` 数据库错误 / `3000` 服务器错误。

## 五、Assumptions & Decisions

1. **依赖装全局 Python 3.12.9**（跟文档 `pip install`，清华源），不建 venv。
2. **密码哈希**用 `werkzeug.security`，无需额外依赖。
3. **新增 token 登录态**：文档没写，但「后续接口对接」必须要它（否则后续接口无法识别当前用户）。用 Flask 自带 itsdangerous，7 天有效。
4. **预留接口只做只读**：`GET /api/posts`、`GET /api/user/profile` 各一个，用于演示「公开分页」与「需登录」两种范式；发帖/回帖的**写**接口本次不实现，留给你照着范式补，代码已在注释里写明步骤。
5. **随机用户名格式**文档未指定，定为 `yunmo_` + 6 位随机小写字母数字；仅在未传 `username` 时使用。文档硬编码的 `admin` 返回值改为真实入库数据。
6. **登录失败区分 1004 / 1005**：文档注释要求「查询用户是否存在」，教学场景提示更明确；若后续要防用户名枚举，可合并提示。
7. **CORS 默认 `*`** 且允许 `Authorization` 头，方便前端 3000 直接调；需要收紧时改 `.env` 的 `CORS_ORIGINS`。
8. **表用 `IF NOT EXISTS`**，`init_db.py` 不 DROP，避免误删数据。
9. **前端零改动**：不加登录页、不装 axios、不加 vite proxy。
10. **安全提醒**：`root/root` 已在对话中明文出现，仅写入被 gitignore 的 `server/.env`；建议后续改本地专用账号。
